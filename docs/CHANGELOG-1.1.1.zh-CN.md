# LanType 1.1.1 变更记录

日期：2026-11-17。本版为 1.1.0 的兼容修复批次，应用包名保持 `app.lantype.keyboard`，versionCode 增至 `3`。运行时仍不申请联网权限。

## 修复

1. **工具舱复制隐私。** 工具舱临时编辑属于私密输入；复制结果也遵守这一边界，不进入普通剪贴板历史、图片预览或同步。复制、剪切在首次写入系统剪贴板时附带私有元数据，输入法进程重新创建后仍可识别。验证包含关闭工具舱后才到达的通知、补读、剪切失败时保留原文，以及后续普通复制正常入库。
2. **连续语音中英切换。** Whisper 的识别语言在引擎创建时固定。同一套权重从中文切到英文时，现在结束旧语言片段、重新创建对应语言的识别会话；沿用现有录音采集和已完成文字。真正兼容当前语言的其他后端保留原复用逻辑。
3. **遗留词库恢复保留数据。** 恢复带有旧 `rime/user`、`rime/shared` 或 `rime/market` 布局的备份时，目标重名或搬移失败的文件留在原位置。仅删除已经搬空的旧目录，不覆盖现有文件，也不混合两个 LevelDB 数据库。冲突资料仍需选择性恢复；保留文件不等于自动合并启用。

## 验证工具与发行

- 增加独立的原生 Android 编辑器测试宿主，使用真实系统输入连接检查普通、密码、邮箱和数字输入框。宿主不替换产品引擎，也不进入发行 APK。
- 增加语音语言会话、旧备份恢复和工具舱剪贴板边界的定向回归；默认 CI 选择集随之更新。
- 应用源码归档和资源验证回执从当前构建配置读取版本号，避免新版本仍标为 1.1.0。
- 中文/英文词库、模型、原生库、资源锁与第三方许可证沿用 1.1.0 的固定内容。对应源码与依赖的复用说明见 [构建与源码](LANTYPE-BUILD-AND-SOURCES.md)。

## 验证范围

具体通过项目、失败修复记录、Android 设备环境、安装包指纹及未执行范围，以 [1.1.1 验证记录](validation-1.1.1/VALIDATION.md) 为准。模拟器功能验证不作为实体手机速度、耗电、麦克风识别质量或 16 KiB 系统运行的结论。

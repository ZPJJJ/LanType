# LanType 1.1.0 变更记录

日期：2026-11-17。基于 LanType 1.0.0 与 CyIME 1.15.94 的产品化批次。

## 本版新增

1. 工具舱的单位换算：时间、字节、长度、角度、温度和帧率/每帧时间，使用明确单位与精度提示。算术表达式继续使用上游计算器。
2. 显式读取选区的文本工具：常见隐私标识遮罩、JSON 排版、URL 与 UTF-8 Base64 编解码。预览后插入或替换。
3. 动态模板：日期、时间、日期时间、一个光标槽和经确认读取的剪贴板。内置笔记、C#、Lua 示例，并可主动保存一个自定义模板。
4. 工具舱会话保护：密码/受限字段拒绝执行，提交前核对会话、连接、组字状态、选区和原文，目标变化时作废旧预览。
5. 设置中的离线许可全文阅读器。

## 资源与发行调整

- 美式英文系统词表改为 SCOWL，并从同一来源重新生成 Trie、Rime 英文、九键和十四键索引；原始排序不冒充真实语料词频。
- 中文基础词典改为 AOSP/rime-pinyin-simp 与 CC-CEDICT，保留上游方案代码和明确授权的辅助码表。
- 语音改为 Whisper multilingual base INT8；保留本地 Silero VAD 和 PP-OCRv5 OCR。
- 中文手写改为 MakeMeAHanzi 笔顺模板；重新生成原创拉丁字母模板及按键音效。
- 移除 MathWriting、Google10000、来源混合的旧统计表，以及本轮没有充分确认来源的旧模型、字体和附加资源。未将旧资源换个文件名继续分发。
- 原生预编译提取改为白名单，只恢复必要库和 Java 绑定，不再恢复旧 APK assets。
- 记录资源来源、固定版本、许可证、校验值和生成步骤；补齐对应原生源码及许可证归档。
- target API 更新为 36；包名保持 `app.lantype.keyboard`，版本代码为 2。

## 隐私与权限

- 保持无 `INTERNET` 权限，禁用运行时在线更新和联网服务。
- 移除短信、通讯录及网络状态权限，验证码改为手动复制粘贴，关闭旧短信自动复制偏好。
- 工具临时文本不自动落盘；用户明确保存的模板留在本机。剪贴板模板单独请求确认。

## 效果变化与验证边界

语音、手写与系统词库更换后，需要重新评估速度、准确率和候选排序。单字笔顺模板不等同于旧神经手写模型；Whisper 片段解码不等于实时流式识别。旧版截图、测试数和性能成绩不作为本版证据。

主流输入能力多数继承自 CyIME/Xime/Rime，本版新增内容以上述条目为准。付费发行应遵守 GPL 和各资源许可，并在真实设备、升级迁移和发行渠道验收后推进。实际已通过及未执行项目以同版本验收报告为准。

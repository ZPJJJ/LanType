# 澜语输入法 1.1.0 使用说明

## 安装与启用

适用设备：Android 9 及以上的 ARM64 手机。包名为 `app.lantype.keyboard`，可与手机原有输入法并存。安装前核对同版本发行记录中的 APK SHA-256 与签名证书摘要。

1. 打开 APK，按系统提示安装。
2. 打开「澜语输入法」，通过启用向导进入系统输入法设置，打开澜语后返回。
3. 等待随包词库和模型从 APK 解压部署完成。首次准备需要额外存储空间，不需要网络。
4. 点击选择输入法，在系统选择器中选择澜语。
5. 打开普通文字输入框，通过中英键切换；在「语言与方案」调整全拼、九键、双拼和布局。

系统菜单名称随手机品牌变化。也可在手机「设置 → 语言与输入法／键盘 → 默认输入法」中选择。安装包大小不等于解压后占用或运行内存，请为首次资源部署留出空间。

## 从 1.0.0 升级

官方 1.1.0 应沿用原包名和签名，直接安装更新。安装前使用应用的本地备份功能导出个人词库、设置和常用语，保管好备份。不要通过卸载来解决签名不匹配，否则应用私有数据可能丢失；先核对来源和签名。

本轮更换系统词库、语音和手写路径，旧系统资源与偏好需要迁移；用户自行导入的文件不因此变成官方认可资源。升级后的词频排序、识别速度和手写效果可能变化，需重新试用。具体已验证的迁移项目以本版验收报告为准。

## 工具舱的三个用法

从键盘工具栏或工具菜单打开「工具舱」。如果工具栏空间不足，在工具列表查找；可以在工具栏配置中调整入口。

### 随手算

选择示例或点「编辑」输入 `2.5 MiB → B`，生成预览，再点插入。`KB` 按 1000 字节，`KiB` 按 1024 字节；这是字节换算，不把小写 `b` 的 bit 单位当作字节。还可输入 `60 fps → ms/frame`、`180 deg → rad`，或使用原计算器支持的算术表达式。

### 选中文字处理

先在目标应用选中文字，再打开工具舱并主动点「读取选区」。选择隐私遮罩、JSON 排版、URL 编解码或 Base64 编解码，检查预览后替换选区。若输入框、选区或原文已变化，必须重新读取和预览。

隐私遮罩只覆盖常见格式。发送前检查姓名、地址及未匹配信息。JSON 排版保留原数字文字，不会把大整数改成浮点近似值；URL 解码使用百分号编码语义，不把 `+` 自动当成空格。

### 动态模板

可使用笔记、C#、Lua 示例，或编辑自己的模板：

```text
{{date}} {{time}}
处理记录：{{cursor}}
```

插入时按手机本地时间展开，并尝试把光标放到 `{{cursor}}` 位置。每个模板最多一个光标槽；少数目标编辑器可能拒绝光标定位，界面会说明文字已插入，避免重复提交。

支持 `{{datetime}}` 和 `{{clipboard}}`。包含剪贴板变量时，须单独确认读取，之后仍需预览并插入。点击「保存模板原文」才会保存一个自定义模板；临时输入和展开结果不会自动保存。

## 其他离线功能

- 中文：全拼、九键、双拼、简繁、模糊音和本地词库。
- English (US)：补全、滑行、美式词形优先与错拼候选；例如 `colour` 可提供 `color`，`teh` 可提供 `the`，用户仍能选择原文。
- 语音：麦克风入口使用随包 Whisper，第一次使用按需授权。按语音片段解码，处理速度取决于设备；不承诺实时流式出字。
- 中文手写：按常规笔顺写单字。使用笔顺模板，不承诺连笔、草书或整行识别。
- 图片识字：PP-OCRv5 在本机处理相机或所选图片，按需申请权限。
- 剪贴板、常用语、Emoji、光标操作、主题和布局沿用上游能力。

输入法不读取短信或通讯录。验证码请在短信应用或系统通知中复制后粘贴。应用没有网络更新、在线模型下载、云同步、云端 AI、声纹区分或随包日语/中英翻译能力。

## 资源与许可

在「本地资源」管理支持的本地词库、方案、模型和插件文件。删除随包模型后，可从本地模型管理页恢复 APK 内的资源。模型结构、文件名与清单必须兼容，不能仅凭文件扩展名判断可用性。

「关于 → 开源许可证／鸣谢」可离线阅读随包许可全文。点击来源链接会由外部浏览器处理。第三方资源保留各自条款，本地导入不代表官方拥有其再分发许可。

## 反馈与验证

同版本验收记录区分编译、宿主测试、界面渲染与真实 ARM64 设备验收。报告问题时记录手机型号、Android 版本、具体操作与实际现象；优先使用虚构文本复现，不默认上传原始输入、录音或截图中的私人信息。

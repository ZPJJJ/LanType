- [x] 新版输入与工具舱的 20 类、124 项去重定向测试通过；命令、历次失败和最终结果已保存。这不等于上游全部测试套件已运行。
- [x] 最终 APK 包名、versionCode、versionName、最小/目标 Android 版本和签名证书已核对。
- [x] 最终合并权限无 INTERNET、短信、通讯录和应用安装权限；麦克风、相机及图片等权限与隐私说明相符。
- [x] 最终 APK 与源码资源锁匹配：379 个主 assets、11 个原创 WAV，最终包的 2,164 个 ZIP 项通过扫描。
- [x] 实际分发原生库的固定来源、许可与必要修改已记录，70 份源码归档备齐；两个 CameraX JNI 已从固定源码重编。全套第三方库未逐一重编或建立字节级复现。

- [ ] 已安装上一版的设备完成升级，个人词库/设置未被删除，停用模型不会被旧偏好误启用。
- [x] 密码/受限字段、过期选区、输入框切换、组字和异步按键边界的工具舱定向测试通过；真机跨应用行为仍随设备验收检查。
- [ ] 小屏、大字体、横竖屏和系统导航区域检查完成，保存没有个人内容的视觉证据。

# 澜语输入法隐私说明

适用范围：LanType 1.1.0 官方离线构建。更新日期：2026-11-17。

## 本地处理

本版 Android 清单移除 INTERNET 权限。普通键盘、随包词库、语音、手写、图片识字与工具舱均在设备上处理，不由输入法向服务器上传输入内容、录音、笔迹、图片或使用统计。开发者不经营输入内容收集服务。系统、图片来源应用和接收文字的目标应用有各自的数据处理方式。

应用不要求创建账户，不包含广告、联网激活和后台自动更新。外部网页或销售渠道由系统浏览器/商店打开，适用该服务自身的隐私规则。

## 输入与本地数据

设置、个性化词频、用户词库、常用语与剪贴板历史保存在应用私有目录。用户可以在对应界面清理，也可导出到自己选择的文件。本版已禁用系统云备份；设备间迁移仍受 Android 版本、厂商实现和应用迁移规则影响，不能据此保证所有换机工具都无法复制应用数据。导出文件的保管由用户决定，分享前应检查是否含私人数据。相关系统行为见 [Android 备份说明](https://developer.android.com/identity/data/autobackup)。

密码、禁用建议或禁止个性化学习的输入框遵循其对应保护规则。无痕模式可用于普通输入的个性化学习控制。不要将本地处理理解为加密保险箱：设备被解锁、root、恶意软件控制或主动导出分享后，数据可能受到其他方式访问。

## 工具舱

工具舱只有在用户点击读取选区、或确认把剪贴板用于模板时才读取对应文本。结果先显示预览，再由用户选择插入或替换。切换输入框、选区变化或编辑器限制发生变化后，应重新读取/预览再提交。

手机号、邮箱等遮罩是常见格式匹配，不是识别所有个人信息的保证。用户应在发送前检查姓名、地址、账号、上下文及未匹配的标识。临时处理文本和展开结果不会自动保存；只有用户主动点击“保存模板原文”时，才在应用私有目录保存一个自定义模板，之后可覆盖或清除应用数据。工具不把文本用于跨用户训练。

## 权限

| 权限/能力 | 使用时机与目的 |
| --- | --- |
| 麦克风 | 用户主动启动离线语音输入时请求；拒绝后仍可正常打字 |
| 相机 | 用户选择拍照识字时请求 |
| 图片读取/系统选取 | 用户选择图片识字或开启相关剪贴板图片能力时按 Android 版本请求 |
| 振动 | 按键触感，可在设置中关闭 |
| 输入法服务绑定 | 系统启用输入法所需；输入法只向用户当前编辑器提交内容 |

本版不申请读取通讯录、接收短信或安装应用权限。验证码由用户在短信应用或系统通知中复制，再手动粘贴。网络同步与需要联网的扩展不能在本版工作。

## 本地导入与反馈

用户可导入兼容词库、设置或插件文件。导入内容的来源、许可与质量需要用户自行选择；不要导入不可信代码或含他人私人数据的资源。官方随包资源与来源清单单独列示。

错误日志由用户在设备上查看。主动提交问题前请去掉个人输入、剪贴板、录音、地址和密钥；公开 GitHub Issue 不是私密渠道。维护者只会收到用户主动提交到对应渠道的信息，不会自动获得手机中的数据。

卸载应用会由 Android 删除应用私有目录，用户另行导出的文件不会随卸载自动消失。清除全部数据会删除本地个性化和配置，请先确认需要保留的内容。
